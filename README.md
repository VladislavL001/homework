# IT-Bank

## Описание:
Проект состоит из нескольких модулей. Каждый модуль создан с целью решения
банковских задач.

1. В модуле masks.py реализвоаны функции маскировки номера
2. В модуле widget.py реализованы функции переформатирования номера
3. В модуле processing.py реализованы функции сортировки
4. В модуле generators.py реализованы функции с генераторами
5. В модуле decorators.py реализован декоратор
6. transaction_proc.py реализованы функции для чтения csv&xlsx файлов
7. operations.py реализованы функции для работы с описанием
8. main.py реализована основная логика программы
## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/VladislavL001/homework.git
```
2. Установите Poetry, если он еще не установлен:
```
pip install poetry
```
3. Установка зависмостей
```
poetry install
```

## Тестирование
Проект покрыт юнит-тестами. Для запуска тестов
выполните комадну:
```
pytest
```
